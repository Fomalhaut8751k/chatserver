# chatserver
基于muduo，mysql，redis，nginx等的集群聊天服务器，包括单对单聊天，群聊，添加好友，添加群聊等功能

2. 2025.8.31
    修复了非聊天页面下收到聊天消息与其他消息的冲突

    ————当用户登陆后，如果有其他用户发来消息，那么此时查看好友列表得到的可能什么都没有，即使他有好友，之后的查看或者刷新后就没有错。
    ————当用户登录后，如果有其他用户发来消息


    设计一个独立的消息接受线程，在用户登录后即开启，它包含唯一的recv，保证send和recv之间不会混乱。
    用户在登陆状态下，如果有人/群聊发来消息，且此时用户处在与该人/群聊的聊天页面上，就直接显示页面
    否则，就把消息存放到一个暂存的队列中，当打开对应的聊天页面时，这些消息就会优先显示出来。
